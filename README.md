# MCP Vetter Fixture Target

This is a **public test fixture** for the MCP Vetter Agent security auditor.

It contains intentional vulnerabilities:
- CWE-22: Unrestricted file access
- CWE-89: SQL injection
- CWE-95: Unsafe eval()

**Purpose:** Demonstrate that the MCP Vetter agent correctly identifies security issues in third-party MCP servers.

**Audit trail:** See [Issues](https://github.com/hemv-857/mcp-vetter-fixture-target/issues) for security audit reports.
